Preguntas cortas

Pregunta 1 · 0,5 puntos
Explica la diferencia entre crear un hilo heredando de Thread e implementando Runnable. ¿Cómo se lanza en cada caso?
  • Heredando de Thread: class MiHilo extends Thread, se sobrescribe run() y se lanza con new MiHilo().start().
  • Implementando Runnable: class MiHilo implements Runnable, se implementa run() y se lanza con new Thread(new MiHilo()).start().

Con Runnable la clase aún puede heredar de otra (Java no tiene herencia múltiple). En ambos casos se lanza con start(), nunca con run() (que ejecutaría el código en el hilo actual).

Pregunta 2 · 1 punto
¿Qué es un socket? Describe los pasos que sigue un servidor y un cliente para establecer una comunicación y qué método activa al servidor.

Socket: punto de conexión entre dos procesos, identificado por una IP y un puerto.

ServidorCliente
1. Crear socket (new ServerSocket(puerto): socket + bind + listen)1. Crear socket (new Socket(ip, puerto)); el SO le asigna un puerto aleatorio
2. accept(): espera (bloqueante) y acepta la conexión entrante → devuelve un Socket2. Se conecta al servidor
3. leer() con BufferedReader / escribir() con PrintWriter3. escribir() / leer()

Lo que activa al servidor es accept(). El puerto del cliente y del servidor deben coincidir en la conexión y debe haber un protocolo acordado.

Pregunta 3 · 1,5 puntos
Protocolo FTP: ¿cuántas conexiones utiliza y para qué? Explica el comando PORT 192,168,1,10,19,136 y qué significan los códigos de respuesta 2yz, 3yz y 5yz.
  • Dos conexiones: control (puerto 21; comandos y respuestas entre los Protocol Interpreter) y datos (puerto 20; transferencia de ficheros entre los Data Transfer Process).
  • PORT h1,h2,h3,h4,p1,p2 indica al servidor a qué IP y puerto debe conectarse para los datos. Aquí: IP 192.168.1.10 y puerto = p1·256 + p2 = 19·256 + 136 = 5000.
  • 2yz: comando ejecutado correctamente (200 Command okay). 3yz: respuesta intermedia positiva, se espera más información (331 User name okay, need password). 5yz: negativa definitiva (550 Access denied).
  • Comandos básicos: USER/PASS acceso, CWD cambiar directorio, RETR descargar, STOR subir, QUIT salir.

Preguntas de programación

Pregunta 4 · 0,5 puntos

El siguiente servidor atiende bien al primer cliente que se conecta, pero un segundo cliente conecta y nunca recibe respuesta. ¿Por qué? ¿Cómo se soluciona?

public void ejecutar() {
    try {
        ServerSocket serverSocket = new ServerSocket(5050);
        while (true) {
            Socket socket = serverSocket.accept();
            BufferedReader br = new BufferedReader(new InputStreamReader(socket.getInputStream()));
            PrintWriter pw = new PrintWriter(new OutputStreamWriter(socket.getOutputStream()));
            String linea;
            while ((linea = br.readLine()) != null) {
                pw.println("Recibido: " + linea);
                pw.flush();
            }
        }
    } catch (IOException e) { e.printStackTrace(); }
}

El servidor tiene un único hilo: mientras atiende al primer cliente está dentro del bucle interno de readLine() y no vuelve a accept() hasta que ese cliente se desconecta. El segundo cliente conecta (el SO lo deja en la cola) pero nadie lo atiende.

Solución: servidor multihilo. El hilo principal solo hace accept() y por cada cliente lanza un hilo que lleva la conversación:

while (true) {
    Socket socket = serverSocket.accept();
    new HiloServidor(socket).start();   // el bucle de lectura va dentro del run() del hilo
}
Pregunta 5 · 0,5 puntos

¿Qué salida produce el siguiente programa? Explica por qué no es concurrente.

public class Main {
    public static void main(String[] args) {
        Thread t = new Thread(new Tarea());
        System.out.println("A");
        t.run();
        System.out.println("B");
    }
}
class Tarea implements Runnable {
    public void run() {
        System.out.println(Thread.currentThread().getName());
    }
}

Salida: A, main, B (siempre en ese orden).

Se ha llamado a run() en lugar de start(): run() es un método normal y se ejecuta en el hilo actual (main), secuencialmente; no se crea ningún hilo nuevo. Con t.start() se ejecutaría en Thread-0 y el orden entre su mensaje y «B» no estaría garantizado.

Pregunta 6 · 0,5 puntos

¿Cuál es la salida de este programa? ¿Y si se elimina la línea h.join();?

public class Main {
    public static void main(String[] args) throws InterruptedException {
        Thread h = new Thread(() -> {
            try { Thread.sleep(500); } catch (InterruptedException e) { }
            System.out.println("A");
        });
        h.start();
        System.out.println("B");
        h.join();
        System.out.println("C");
    }
}
  • Con join(): B, A, C. El main imprime «B» enseguida y con join() espera a que el hilo (que duerme 500 ms) termine e imprima «A»; solo entonces imprime «C».
  • Sin join(): B, C, A. El main no espera al hilo secundario, que tarda 500 ms.
Pregunta 7 · 0,5 puntos

Al ejecutar el cliente aparece la siguiente excepción. Indica dos posibles causas.

java.net.ConnectException: Connection refused
    at java.base/sun.nio.ch.Net.connect0(Native Method)
    at java.base/java.net.Socket.<init>(Socket.java:...)

El cliente no ha podido establecer la conexión con el servidor:

  1. El servidor no está arrancado (nadie hace accept() en ese puerto) — hay que lanzar primero el servidor.
  2. El puerto o la IP del cliente no coinciden con los del servidor (new Socket("127.0.0.1", 5050) vs. new ServerSocket(8000)).

También: un firewall que bloquea el puerto, o un servidor que ha terminado/caído.

Pregunta 8 · 5 puntos

La biblioteca de la universidad quiere un sistema de gestión de préstamos de libros al que se conecten los clientes mediante Sockets. El servidor ya está implementado: mantiene una Hashtable<String, Libro> compartida (clave: ISBN) con los métodos boolean addLibro(String isbn, String titulo) (devuelve false si ya existe) y Libro getLibro(String isbn) (devuelve null si no existe), y por cada cliente lanza un HiloGestionBiblioteca pasándole el Socket y el Servidor. Se pide implementar solamente la clase HiloGestionBiblioteca (y la clase Libro que necesite): crear los buffers, leer los comandos línea a línea y escribir la respuesta. Si el cliente envía EXIT o se desconecta, el hilo cierra el socket y termina.

ComandoDescripción y respuestas
ALTALIBRO isbn tituloDa de alta un libro (el título puede tener espacios).
→ Ok. Libro insertado
→ Error. El libro ya existe
PRESTAR isbnRegistra el préstamo con la hora del servidor.
→ Ok. Libro prestado. 2025-11-11T17:05
→ Error. El libro ya esta prestado
→ Error. El libro no existe
DEVOLVER isbnRegistra la devolución y calcula los días de préstamo.
→ Ok. Libro devuelto. Dias de prestamo: 3
→ Error. El libro no esta prestado
ESTADO isbn→ El libro Titulo esta disponible
→ El libro Titulo esta prestado desde: 2025-11-11T17:05
PRESTAMOS isbnNúmero total de veces que se ha prestado el libro.
→ Ok. El libro se ha prestado 4 veces

Condiciones: no se puede prestar un libro ya prestado ni devolver uno que no lo está. Dos clientes no pueden prestar a la vez el mismo libro. Se supone que existe la clase GestionFechas con los métodos estáticos: Timestamp getHoraActual(), int getDiasEntre(Timestamp inicio, Timestamp fin) y String getTexto(Timestamp fecha).

Plan: (1) Libro con isbn, título, fecha de préstamo (null = disponible) y contador de préstamos; (2) el hilo crea los buffers, lee en bucle, hace split(" ", 3) y despacha con un switch; (3) las operaciones sobre un libro concreto se hacen dentro de synchronized(libro) para que dos clientes no presten a la vez el mismo.

Clase Libro

import java.sql.Timestamp;

public class Libro {
    private String isbn;
    private String titulo;
    private Timestamp fechaPrestamo;   // null si esta disponible
    private int vecesPrestado = 0;

    public Libro(String isbn, String titulo) {
        this.isbn = isbn;
        this.titulo = titulo;
    }
    public String getIsbn() { return isbn; }
    public String getTitulo() { return titulo; }
    public boolean estaPrestado() { return fechaPrestamo != null; }
    public Timestamp getFechaPrestamo() { return fechaPrestamo; }

    public void prestar(Timestamp fecha) {
        this.fechaPrestamo = fecha;
        this.vecesPrestado++;
    }
    public void devolver() { this.fechaPrestamo = null; }
    public int getVecesPrestado() { return vecesPrestado; }
}

Clase HiloGestionBiblioteca (la que se pide)

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.net.Socket;
import java.sql.Timestamp;

public class HiloGestionBiblioteca extends Thread {
    private Socket socket;
    private Servidor servidor;
    private BufferedReader br;
    private PrintWriter pw;

    public HiloGestionBiblioteca(Socket socket, Servidor servidor) {
        this.socket = socket;
        this.servidor = servidor;
    }

    @Override
    public void run() {
        try {
            this.br = new BufferedReader(new InputStreamReader(this.socket.getInputStream()));
            this.pw = new PrintWriter(new OutputStreamWriter(this.socket.getOutputStream()));

            String linea;
            while ((linea = this.br.readLine()) != null) {
                if (linea.trim().equalsIgnoreCase("EXIT")) break;
                this.pw.println(this.procesar(linea));
                this.pw.flush();
            }
        } catch (IOException e) {
            System.out.println("Conexion finalizada");
        } finally {
            try { this.socket.close(); } catch (IOException e) { }
        }
    }

    private String procesar(String linea) {
        String[] partes = linea.trim().split(" ", 3);
        switch (partes[0].toUpperCase()) {
        case "ALTALIBRO":
            if (partes.length < 3) return "Error. Uso: ALTALIBRO isbn titulo";
            return this.servidor.addLibro(partes[1], partes[2])
                    ? "Ok. Libro insertado" : "Error. El libro ya existe";
        case "PRESTAR":
            return this.prestar(partes);
        case "DEVOLVER":
            return this.devolver(partes);
        case "ESTADO":
            return this.estado(partes);
        case "PRESTAMOS":
            return this.prestamos(partes);
        default:
            return "Error. Comando no reconocido";
        }
    }

    private String prestar(String[] partes) {
        if (partes.length < 2) return "Error. Uso: PRESTAR isbn";
        Libro libro = this.servidor.getLibro(partes[1]);
        if (libro == null) return "Error. El libro no existe";
        synchronized (libro) {                       // dos clientes no pueden prestar a la vez el mismo libro
            if (libro.estaPrestado()) return "Error. El libro ya esta prestado";
            libro.prestar(GestionFechas.getHoraActual());
            return "Ok. Libro prestado. " + GestionFechas.getTexto(libro.getFechaPrestamo());
        }
    }

    private String devolver(String[] partes) {
        if (partes.length < 2) return "Error. Uso: DEVOLVER isbn";
        Libro libro = this.servidor.getLibro(partes[1]);
        if (libro == null) return "Error. El libro no existe";
        synchronized (libro) {
            if (!libro.estaPrestado()) return "Error. El libro no esta prestado";
            int dias = GestionFechas.getDiasEntre(libro.getFechaPrestamo(), GestionFechas.getHoraActual());
            libro.devolver();
            return "Ok. Libro devuelto. Dias de prestamo: " + dias;
        }
    }

    private String estado(String[] partes) {
        if (partes.length < 2) return "Error. Uso: ESTADO isbn";
        Libro libro = this.servidor.getLibro(partes[1]);
        if (libro == null) return "Error. El libro no existe";
        synchronized (libro) {
            if (libro.estaPrestado())
                return "El libro " + libro.getTitulo() + " esta prestado desde: " + GestionFechas.getTexto(libro.getFechaPrestamo());
            return "El libro " + libro.getTitulo() + " esta disponible";
        }
    }

    private String prestamos(String[] partes) {
        if (partes.length < 2) return "Error. Uso: PRESTAMOS isbn";
        Libro libro = this.servidor.getLibro(partes[1]);
        if (libro == null) return "Error. El libro no existe";
        return "Ok. El libro se ha prestado " + libro.getVecesPrestado() + " veces";
    }
}

Servidor (ya implementado en el enunciado; se incluye para poder probarlo)

import java.io.IOException;
import java.net.ServerSocket;
import java.net.Socket;
import java.util.Hashtable;

public class Servidor {
    public static final int PUERTO = 9000;
    private Hashtable<String, Libro> libros = new Hashtable<String, Libro>();

    public synchronized boolean addLibro(String isbn, String titulo) {
        if (libros.containsKey(isbn)) return false;
        libros.put(isbn, new Libro(isbn, titulo));
        return true;
    }
    public synchronized Libro getLibro(String isbn) {
        return libros.get(isbn);
    }

    public void ejecutar() {
        try (ServerSocket serverSocket = new ServerSocket(PUERTO)) {
            System.out.println("Servidor de biblioteca esperando clientes...");
            while (true) {
                Socket socket = serverSocket.accept();
                new HiloGestionBiblioteca(socket, this).start();
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    public static void main(String[] args) {
        (new Servidor()).ejecutar();
    }
}
