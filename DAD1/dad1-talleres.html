Taller DAD I - Parte teórica

Teoría 1
¿Qué es un hilo y qué ventajas tiene?

Un hilo de ejecución es la secuencia única de control de flujo dentro de un programa; la unidad de código más pequeña que se puede ejecutar.

  • Ejecución de tareas lentas.
  • No paralizar el programa principal mientras se ejecutan otras tareas.
  • Evitar bloqueos inaceptables: un bloqueo indefinido de un proceso se mitiga usando hilos.
  • Manejo de múltiples tareas: un proceso puede dividirse para hacer varias tareas a la vez.
Teoría 2
Esquema FTP (el taller incluye el diagrama): ¿qué componentes y conexiones intervienen?

Cliente (User) y servidor, cada uno con:

  • Interfaz de usuario (User Interface) y User-PI / Server-PI (Protocol Interpreter) → conexión de control (comandos/respuestas), servidor escuchando en el puerto 21.
  • User-DTP / Server-DTP (Data Transfer Process) → conexión de datos (puerto 20) que transporta los ficheros.
  • Cada lado accede a su propio sistema de ficheros.

Variante (esquema II): un cliente controla dos servidores: con PASV a A (que responde 227 Entering Passive Mode A1,A2,A3,A4,a1,a2) y PORT a B con esos valores; luego STOR en A y RETR en B, y B se conecta directamente a A para los datos.

Teoría 3
Programación distribuida: sistema distribuido, IPC y operaciones primitivas.
  • Programación distribuida: varios computadores interconectados que colaboran para realizar una tarea.
  • Sistema distribuido: computadores independientes conectados por red que trabajan juntos; no comparten memoria ni espacio de ejecución. Computación distribuida = la que se hace en él.
  • IPC (comunicación entre procesos): fundamental; procesos independientes se comunican para colaborar. Requiere un protocolo. Tipos: unicast y multicast. El SO proporciona mecanismos.
  • Operaciones primitivas: enviar, recibir, conectar, desconectar; los procesos las invocan de forma independiente.
Teoría 4
Inicializar hilos: ¿de qué dos formas se hace?
  1. Heredando de Thread: nueva clase que extiende Thread, se implementa run() y se lanza con start().
  2. Implementando Runnable: clase que implementa la interfaz, se implementa run() y se lanza con new Thread(obj).start().
Teoría 5
Bloqueo de acceso: ¿qué es y cuáles son las dos soluciones?

Se produce cuando una petición que espera la finalización de una operación no se desbloquea, lo que puede llevar a un bloqueo indefinido.

  1. Temporizadores (timers): límite de tiempo de espera para que el proceso no quede bloqueado si la respuesta no llega.
  2. Proceso hijo o hilo de ejecución: el programa realiza varias tareas simultáneamente; útil para tareas lentas como conexiones de red o grabación en disco.

Ejercicio 1 · Primer hilo (extends Thread)

Crea un hilo que imprima 5 veces «Ejecución: i» durmiendo 500 ms entre cada una. Lánzalo desde el main, que espera 1,2 s y escribe «Lanzado...». ¿En qué orden salen los mensajes?

MiHilo

package edu.ucam.hilos.primerhilo;

import java.util.Iterator;

public class MiHilo extends Thread{
    
    @Override
    public void run() {
        for (int i = 0 ; i< 5 ; i++) {
            System.out.println("Ejecución: " + i);
            
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            
        }
    }

}

Root

package edu.ucam.hilos.primerhilo;

public class Root {

    public static void main(String[] args) {
        MiHilo miHilo = new MiHilo();
        miHilo.start();
        
        try {
            Thread.sleep(1200);
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        
        System.out.println("Lanzado...");
    }
}

Salida: Ejecución 0 (t=0), Ejecución 1 (0,5 s), Ejecución 2 (1,0 s), Lanzado... (1,2 s), Ejecución 3 (1,5 s), Ejecución 4 (2,0 s). El main y el hilo avanzan en paralelo.

Ejercicio 3 · Esperar y parar un hilo (join / interrupt)

Un hilo duerme 10 s. El main lo lanza y lo espera como máximo 5 s con join(5000). ¿Qué pasa? ¿Y si descomentamos interrupt()?

package edu.ucam.hilos.pararhilo;

public class UnHilo extends Thread {
    
    public void run() {        
        try {
            
            System.out.println("[Hilo secundario]: Estoy ejecutándome...");
        
            Thread.sleep(10000);
            
            System.out.println("[Hilo secundario]: Finalizo hilo");
        
        } catch (InterruptedException e) {
            System.out.println("Excepción en hilo: se ha interrumpido");
        }
            
        }

}
package edu.ucam.hilos.pararhilo;

public class Root {

    public void ejecutar() {        
        try {
            
            UnHilo unHilo = new UnHilo();
            
            unHilo.start();
            
            System.out.println("[Main]: Me paro antes del join");
            unHilo.join(5000);                    
            
            //unHilo.interrupt();
            
            System.out.println("[Main]: Fin en Root");
            
        } catch (InterruptedException e) {
            
            e.printStackTrace();
        }
        
        
        
    }
    
    public static void main(String[] args) {
        (new Root()).ejecutar();
    }

}

Sin interrupt(): tras 5 s el main imprime «Fin en Root» pero el hilo secundario sigue vivo y a los 10 s imprime «Finalizo hilo». Con interrupt() tras el join: el sleep del hilo lanza InterruptedException y se imprime «Excepción en hilo: se ha interrumpido», terminando antes.

Ejercicio 4 · Contador compartido y synchronized

200 hilos incrementan 100 veces un Contador compartido. ¿Qué total esperas (20000)? ¿Qué pasa si sumaUno() no es synchronized?

package edu.ucam.hilos.contador;

//Nombre de clase debe ser Camel Sense. No válidos: contador o cONTADOR...
public class Contador {

    private int total = 0;
    
    public synchronized void sumaUno() {
        this.total = this.total + 1;
    }
    
    public int getTotal() {
        return this.total;
    }
}
package edu.ucam.hilos.contador;

public class HiloContador extends Thread {
    
    private Contador contador;
    
    public HiloContador (Contador contador) {
        this.contador = contador;
    }
    
    public Contador getContador() {
        return contador;
    }

    public void setContador(Contador contador) {
        this.contador = contador;
    }
    
    public void run() {
        
        for(int i = 0 ; i < 100; i++) {
            this.contador.sumaUno();
        }
        
        try {
            Thread.sleep(200);
            
            System.out.println("Total contador: " + this.contador.getTotal());
            
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }
}
package edu.ucam.hilos.contador;

public class Root {

    public void ejecutar() {
        
        Contador contador = new Contador();
        
        for (int i = 0; i < 200; i++) {
            (new HiloContador(contador)).start();
        }
    }
    
    
    public static void main(String[] args) {
        
        Root root = new Root();
        root.ejecutar();
    }
}

Con synchronized, cada hilo ve el total correcto (20000) al terminar. Sin él, this.total = this.total + 1 no es atómico y se pierden incrementos: el total sale menor y distinto en cada ejecución (condición de carrera). El sleep(200) da tiempo a que el resto de hilos acabe antes de imprimir.

Ejercicio 5 · Lanzar y parar hilos desde una interfaz Swing

Ventana con botones «Lanzar hilo» y «Parar hilo», un JTextArea y un JComboBox con los hilos activos. Cada hilo escribe cada segundo en el área de texto hasta que se le pida parar.

  • Hilo (clase main/ventana): atributos textArea y comboHilos; métodos getComboHilos(), escribir(String) (añade al textArea) y addHilo(HiloContador) (añade al combo).
  • HiloContador extends Thread: static int porDondeVoy (id único), boolean running, run() con bucle while(running) + Thread.sleep(1000); si lo interrumpen, captura la excepción y escribe «Hilo finalizado»; método parar() que pone running = false.
  • ActionLanzarHilo (ActionListener): guarda una referencia a la ventana; en actionPerformed crea un HiloContador, se la pasa, hace start() y lo añade al combo.
  • ActionPararHilo: HiloContador h = (HiloContador) mainHilos.getComboHilos().getSelectedItem(); h.parar(); y quita el hilo con comboHilos.removeItem(comboHilos.getSelectedItem()).
public class HiloContador extends Thread {
    private static int porDondeVoy = 0;
    private int id = ++porDondeVoy;
    private volatile boolean running = true;
    private Hilo ventana;

    public HiloContador(Hilo ventana) { this.ventana = ventana; }

    public void parar() { this.running = false; }

    @Override
    public void run() {
        int i = 0;
        try {
            while (running) {
                ventana.escribir("Hilo " + id + ": " + (i++));
                Thread.sleep(1000);
            }
        } catch (InterruptedException e) { }
        ventana.escribir("Hilo " + id + " finalizado");
    }
    @Override public String toString() { return "Hilo " + id; }   // así se ve en el combo
}
volatile garantiza que el hilo vea el cambio de running hecho por el hilo de la interfaz. Los Swing no se modifican desde hilos propios en producción (SwingUtilities.invokeLater), pero para el taller basta con esto.

HiloServidor (aquí está el split + switch)

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.net.Socket;

public class HiloServidor extends Thread {
    private Socket socket;

    public HiloServidor(Socket socket) {
        this.socket = socket;
    }

    @Override
    public void run() {
        try {
            BufferedReader br = new BufferedReader(new InputStreamReader(socket.getInputStream()));
            PrintWriter pw = new PrintWriter(new OutputStreamWriter(socket.getOutputStream()));
            boolean salir = false;
            while (!salir) {
                String linea = br.readLine();
                if (linea == null) break;                  // el cliente cerro la conexion
                String[] partes = linea.split(" ");
                String respuesta = "";
                switch (partes[0].toUpperCase()) {
                case "SUMA":
                    respuesta = "" + (Integer.parseInt(partes[1]) + Integer.parseInt(partes[2]));
                    break;
                case "RESTA":
                    respuesta = "" + (Integer.parseInt(partes[1]) - Integer.parseInt(partes[2]));
                    break;
                case "MULTIPLICA":
                    respuesta = "" + (Integer.parseInt(partes[1]) * Integer.parseInt(partes[2]));
                    break;
                case "EXIT":
                    respuesta = "Adios";
                    salir = true;
                    break;
                default:
                    respuesta = "Comando no reconocido";
                }
                pw.println(respuesta);
                pw.flush();
            }
            socket.close();
        } catch (IOException | NumberFormatException | ArrayIndexOutOfBoundsException e) {
            System.out.println("Conexion finalizada: " + e);
        }
    }
}

Ejercicio 10 · Multas por matrícula

Examen del año pasado. Gestiona multas por matrícula con una Hashtable compartida por todos los hilos. Comandos: ALTA matricula, MULTA matricula cuantia, PAGO matricula cantidad, PENDIENTE matricula, BORRAR matricula, EXIT.

Matricula: ArrayList<Integer> de multas, getCuantiaMultas() (suma), addMulta(), addPago(), getPendiente().

import java.util.ArrayList;

public class Matricula {
    private String numero;
    private ArrayList<Integer> multas = new ArrayList<Integer>();
    private int pagado = 0;

    public Matricula(String numero) {
        this.numero = numero;
    }
    public String getNumero() { return numero; }

    public void addMulta(Integer cuantia) { multas.add(cuantia); }

    public int getCuantiaMultas() {            // suma de todas las multas
        int total = 0;
        for (Integer m : multas) total += m;
        return total;
    }
    public void addPago(int cantidad) { pagado += cantidad; }

    public int getPendiente() { return getCuantiaMultas() - pagado; }
}

Servidor: añade la Hashtable y los métodos de acceso; se pasa a cada hilo (new HiloServidor(socket, this)).

import java.io.IOException;
import java.net.ServerSocket;
import java.net.Socket;
import java.util.Hashtable;

public class Servidor {
    public static final int PUERTO = 5050;
    // Hashtable es thread-safe: todos los hilos comparten esta unica tabla
    private Hashtable<String, Matricula> matriculas = new Hashtable<String, Matricula>();

    public Matricula getMatricula(String numero) { return matriculas.get(numero); }

    public String addMatricula(String numero) {
        if (matriculas.containsKey(numero)) return "Error. La matricula ya existe";
        matriculas.put(numero, new Matricula(numero));
        return "Ok. Matricula insertada";
    }

    public String removeMatricula(Matricula matricula) {
        if (matricula == null) return "Error. La matricula no existe";
        matriculas.remove(matricula.getNumero());
        return "Ok. Matricula borrada";
    }

    public void ejecutar() {
        try (ServerSocket serverSocket = new ServerSocket(PUERTO)) {
            while (true) {
                Socket socket = serverSocket.accept();
                new HiloServidor(socket, this).start();    // se pasa el servidor al hilo
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    public static void main(String[] args) {
        (new Servidor()).ejecutar();
    }
}

HiloServidor: variable salir, bucle hasta EXIT, split, switch; respuesta con el mensaje.

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.net.Socket;

public class HiloServidor extends Thread {
    private Socket socket;
    private Servidor servidor;
    private boolean salir = false;

    public HiloServidor(Socket socket, Servidor servidor) {
        this.socket = socket;
        this.servidor = servidor;
    }

    @Override
    public void run() {
        try (BufferedReader br = new BufferedReader(new InputStreamReader(socket.getInputStream()));
                PrintWriter pw = new PrintWriter(new OutputStreamWriter(socket.getOutputStream()))) {
            while (!salir) {
                String lineaLeida = br.readLine();
                if (lineaLeida == null) break;
                String[] partes = lineaLeida.split(" ");
                String respuesta = "";
                Matricula matricula = null;
                if (partes.length > 1) matricula = servidor.getMatricula(partes[1]);

                switch (partes[0].toUpperCase()) {
                case "ALTA":
                    respuesta = partes.length == 2 ? servidor.addMatricula(partes[1]) : "Error. Uso: ALTA matricula";
                    break;
                case "MULTA":
                    if (partes.length == 3 && matricula != null) {
                        matricula.addMulta(Integer.parseInt(partes[2]));
                        respuesta = "Ok. Multa anadida";
                    } else respuesta = "Error. Uso: MULTA matricula cuantia (la matricula debe existir)";
                    break;
                case "PAGO":
                    if (partes.length == 3 && matricula != null) {
                        matricula.addPago(Integer.parseInt(partes[2]));
                        respuesta = "Ok. Pago registrado";
                    } else respuesta = "Error. Uso: PAGO matricula cantidad (la matricula debe existir)";
                    break;
                case "PENDIENTE":
                    respuesta = matricula != null ? "Pendiente: " + matricula.getPendiente() + " euros"
                            : "Error. La matricula no existe";
                    break;
                case "BORRAR":
                    respuesta = servidor.removeMatricula(matricula);
                    break;
                case "EXIT":
                    respuesta = "Adios";
                    salir = true;
                    break;
                default:

Ejercicio 11 · Materiales (reserva de stock + matar hilos)

Examen del año pasado. Gestiona materiales con Hashtable y además un ArrayList de hilos con id para poder cerrarlos. Comandos: ALTA id cantidad descripcion..., RESERVA id unidades, LISTAR, EXIT (el hilo se mata a sí mismo con matarHilo).

Material: toString() sobrescrito y addReserva() que resta unidades.

public class Material {
    private String id;
    private String descripcion;
    private int cantidad;

    public Material(String id, String descripcion, int cantidad) {
        this.id = id;
        this.descripcion = descripcion;
        this.cantidad = cantidad;
    }
    public String getId() { return id; }
    public int getCantidad() { return cantidad; }

    public boolean addReserva(int unidades) {      // resta unidades si hay stock
        if (unidades <= 0 || unidades > cantidad) return false;
        cantidad -= unidades;
        return true;
    }

    @Override
    public String toString() {
        return id + " - " + descripcion + " (" + cantidad + " uds)";
    }
}

Servidor: Hashtable de materiales, ArrayList de hilos, contador para dar id a cada hilo y matarHilo(id) (busca el hilo y llama a cerrarSocket()).

import java.io.IOException;
import java.net.ServerSocket;
import java.net.Socket;
import java.util.ArrayList;
import java.util.Hashtable;

public class Servidor {
    public static final int PUERTO = 5050;
    private Hashtable<String, Material> materiales = new Hashtable<String, Material>();
    private ArrayList<HiloServidor> hilos = new ArrayList<HiloServidor>();   // para poder "matar" hilos
    private int contadorHilos = 0;

    public synchronized String addMaterial(String id, String descripcion, int cantidad) {
        if (materiales.containsKey(id)) return "Error. El material ya existe";
        materiales.put(id, new Material(id, descripcion, cantidad));
        return "Ok. Material insertado";
    }
    public Material getMaterial(String id) { return materiales.get(id); }

    public synchronized String listar() {
        StringBuilder sb = new StringBuilder();
        for (Material m : materiales.values()) sb.append(m).append(" | ");
        return sb.length() == 0 ? "No hay materiales" : sb.toString();
    }

    public synchronized void matarHilo(int idHilo) {
        for (HiloServidor h : hilos) {
            if (h.getIdHilo() == idHilo) {
                h.cerrarSocket();
                hilos.remove(h);
                break;
            }
        }
    }

    public void ejecutar() {
        try (ServerSocket serverSocket = new ServerSocket(PUERTO)) {
            while (true) {
                Socket socket = serverSocket.accept();
                HiloServidor hilo = new HiloServidor(socket, this, contadorHilos++);
                synchronized (this) { hilos.add(hilo); }
                hilo.start();
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    public static void main(String[] args) {
        (new Servidor()).ejecutar();
    }
}

HiloServidor: la descripción puede llevar espacios → substring + indexOf para quedarse con todo lo que va tras la cantidad.

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.net.Socket;

public class HiloServidor extends Thread {
    private Socket socket;
    private Servidor servidor;
    private int idHilo;
    private boolean salir = false;

    public HiloServidor(Socket socket, Servidor servidor, int idHilo) {
        this.socket = socket;
        this.servidor = servidor;
        this.idHilo = idHilo;
    }
    public int getIdHilo() { return idHilo; }

    public void cerrarSocket() {
        try { socket.close(); } catch (IOException e) { }
    }

    @Override
    public void run() {
        try {
            BufferedReader br = new BufferedReader(new InputStreamReader(socket.getInputStream()));
            PrintWriter pw = new PrintWriter(new OutputStreamWriter(socket.getOutputStream()));
            while (!salir) {
                String lineaLeida = br.readLine();
                if (lineaLeida == null) break;
                String[] partes = lineaLeida.split(" ");
                String respuesta = "";
                switch (partes[0].toUpperCase()) {
                case "ALTA": {   // ALTA id cantidad descripcion con espacios...
                    if (partes.length < 4) { respuesta = "Error. Uso: ALTA id cantidad descripcion"; break; }
                    // substring + indexOf: coge todo lo que hay tras el 3er espacio
                    int inicio = lineaLeida.indexOf(partes[2]) + partes[2].length() + 1;
                    String descripcion = lineaLeida.substring(inicio);
                    respuesta = servidor.addMaterial(partes[1], descripcion, Integer.parseInt(partes[2]));
                    break;
                }
                case "RESERVA": {
                    Material m = partes.length == 3 ? servidor.getMaterial(partes[1]) : null;
                    if (m == null) respuesta = "Error. Uso: RESERVA id unidades (el material debe existir)";
                    else respuesta = m.addReserva(Integer.parseInt(partes[2])) ? "Ok. Reserva realizada" : "Error. Stock insuficiente";
                    break;
                }
                case "LISTAR":
                    respuesta = servidor.listar();
                    break;
                case "EXIT":
                    respuesta = "Adios";
                    salir = true;
                    break;
                default:
                    respuesta = "Comando no reconocido";
                }
                pw.println(respuesta);
                pw.flush();
            }
            servidor.matarHilo(this.idHilo);    // EXIT: el servidor cierra el socket y borra el hilo
        } catch (IOException | NumberFormatException e) {
            System.out.println("Conexion finalizada: " + e);
        }
    }
}
