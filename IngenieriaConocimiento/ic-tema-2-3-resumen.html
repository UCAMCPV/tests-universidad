1. Introducción

¿Qué es evaluar y para qué?

  • Evaluar es cuantificar el rendimiento (calidad de predicción) del modelo con métricas, según el tipo de problema: clasificación, regresión o agrupamiento.
  • Sirve para comparar modelos y elegir el mejor, estimar cómo se comportará en producción y convencer al cliente de que cumplirá su propósito.

Regla básica

  • La evaluación final nunca debe hacerse sobre los datos de entrenamiento, ni siquiera sobre los de validación: se hace con los datos de prueba.
  • Forma más básica: dividir en entrenamiento, validación y prueba; aprender con el primero, validar con el segundo, evaluar con el tercero.
  • A veces no es posible (pocos datos) → se usan técnicas como validación cruzada o bootstrap.

2. Técnicas de evaluación

Holdout

  • Separar aleatoriamente los datos en entrenamiento, validación y prueba. Porcentajes habituales: 60:20:20, 50:20:30, 40:20:40.
  • Problemas: clases no balanceadas (el reparto puede no respetar las proporciones; ej.: 900 de «A» y 100 de «B»); a veces no hay datos suficientes para separar; puede que en entrenamiento queden los datos «fáciles» (o al revés).
  • Holdout estratificado: reparte aleatoriamente respetando las proporciones de cada clase.
  • La validación cruzada contrarresta los dos últimos problemas.

Validación cruzada (cross validation)

  • k-fold: se divide el conjunto en k partes iguales (preferentemente estratificadas; k=10 o k=5), se hacen k aprendizajes: en cada uno una parte es test y las otras k−1 entrenamiento; se devuelve la media de las evaluaciones.
  • Ventajas: buena opción con pocos datos; cada dato aparece exactamente una vez en test; permite medir la varianza entre conjuntos de prueba.
  • Desventaja: tiempo de cómputo.
  • Observaciones: no es un método para aprender un modelo, sino para estimar su capacidad de generalización; se usa p. ej. para ajustar parámetros. Después se suele aprender el modelo con todo el conjunto de entrenamiento y evaluarlo con un conjunto de prueba independiente.
VarianteDescripción
Leave One Out (LOOCV)Un solo dato como test y el resto como entrenamiento; se repite para cada dato. Útil con conjuntos pequeños; costoso con grandes.
Monte Carlo CVCombina reorganización aleatoria de los datos con validación cruzada (particiones aleatorias). Permite subsampling, útil con muchos datos.
Stratified K-FoldLa distribución de clases en cada pliegue es similar a la del conjunto original. Útil con clases desequilibradas.
Time Series CVEspecífica para series temporales: divisiones según el tiempo, simulando predecir el futuro a partir del pasado.

Bootstrap

  • Técnica de resampling: extraer repetidamente muestras de los datos con reemplazo (un dato puede aparecer varias veces o no aparecer).
  • En cada iteración: muestra del mismo tamaño que el dataset; se entrena con ella y se evalúa sobre el conjunto original; se devuelve la media de las iteraciones.
  • Es una estimación optimista, por el gran solape entre entrenamiento y prueba.

3. Métricas de evaluación

Resumen por tipo de problema

ProblemaMétricas
ClasificaciónMatriz de confusión, Accuracy, Precision, Recall (sensibilidad), F1, AUC-ROC, Jaccard, Log Loss
RegresiónR², MSE, RMSE, MAE, MAPE
AgrupamientoValidación interna: SSW, SSB, Silhouette. Validación externa: ARI

Clasificación: matriz de confusión

EstadoSignificado
TP (verdadero positivo)Clasificado como positivo y realmente positivo.
TN (verdadero negativo)Clasificado como negativo y realmente negativo.
FP (falso positivo)Clasificado como positivo, pero realmente negativo.
FN (falso negativo)Clasificado como negativo, pero realmente positivo.

Puede ser binaria o multiclase.

Clasificación: métricas

MétricaFórmulaNotas
Accuracy(TP+TN) / (TP+FP+TN+FN)Proporción de predicciones correctas sobre el total. No adecuada con clases desbalanceadas.
PrecisionTP / (TP+FP)De lo clasificado como positivo, cuánto lo es realmente. Útil para minimizar falsos positivos (ej.: detección de spam).
Recall (sensibilidad, ratio de verdaderos positivos)TP / (TP+FN)De los positivos reales, cuántos detecta. Útil para minimizar falsos negativos (ej.: detección de cáncer).
F1 Score2 · (recall·precision) / (recall+precision)Media armónica de precision y recall; equilibra ambas. Suele comportarse mejor con datasets desbalanceados.
AUC-ROCÁrea bajo la curva ROC (TPR frente a FPR)Capacidad del modelo para distinguir entre clases positivas y negativas. Útil cuando las probabilidades de las clases importan.
Jaccard (IoU)|A ∩ B| / |A ∪ B|Clasificación y segmentación; Intersection over Union; superposición de conjuntos.
Log Loss−(y·log p + (1−y)·log(1−p))Discrepancia entre predicciones y valores reales (logarítmica). Muy importante con modelos de probabilidad.

Regresión

MétricaDescripción
R²Proporción de la variabilidad de la variable dependiente explicada por el modelo. Entre 0 y 1; 1 = ajuste perfecto.
MSEPromedio de los errores al cuadrado. Penaliza los errores grandes más que el MAE.
RMSERaíz cuadrada del MSE: error promedio en la misma unidad que la variable objetivo. También penaliza más los errores grandes que el MAE.
MAEPromedio de las diferencias absolutas entre predicciones y valores reales.
MAPEPromedio de los errores porcentuales absolutos; interpreta el error en porcentaje.

Agrupamiento

MétricaTipoDescripción
SSW (Sum of Squared Within)Validación internaEvalúa la cohesión de los clústeres. Valores bajos deseados.
SSB (Sum of Squared Between)Validación internaEvalúa la separación entre clústeres (distancia interclúster). Valores altos deseados.
Silhouette ScoreValidación internaSimilitud de un punto con su propio clúster (cohesión) frente a otros (separación): a = distancia media al clúster propio, b = distancia media al clúster vecino más próximo. Valor entre −1 y 1; más alto = clústeres más densos y separados.
ARI (Adjusted Rand Index)Validación externaCompara las etiquetas reales con las asignadas por el algoritmo; requiere conocer las etiquetas. Mide la similitud entre ambas asignaciones.
