Resumen: Bosques y dominios de Active Directory

Cómo se organiza una infraestructura Active Directory: el dominio, el árbol de dominios y el bosque, y por qué la clave está en si el espacio de nombres es continuo o no.

1. La jerarquía de Active Directory y el dominio

Una jerarquía de entidades seguras

Una infraestructura Active Directory funciona según una jerarquía que representa una entidad segura que alberga usuarios y equipos. Esa infraestructura forma un árbol compuesto de dominios, árboles de dominio o bosques.

Los distintos dominios se comunican entre sí mediante relaciones de confianza.

BOSQUE              un único esquema · su primer dominio = dominio raíz del bosque
 └── ÁRBOL(ES)      dominios con un espacio de nombres continuo
      └── DOMINIOS  entidad administrativa y de seguridad (usuarios, equipos, directivas)
          ↔ comunicados entre sí por relaciones de confianza

Dominio

Un dominio es una entidad administrativa de Active Directory dentro de la que se comparten ciertas funcionalidades y características.

  • Es una entidad de seguridad que alberga usuarios y equipos.
  • Representa un perímetro en el que se definen las directivas.

Ejemplo del documento: el dominio Nextinfo.priv, dibujado como un triángulo aislado.

Dominio = límite administrativo y de seguridad: dentro de él están los usuarios y equipos y se definen las directivas.

2. Árbol de dominios

Dominios que comparten un espacio de nombres

Un árbol es un conjunto de dominios que comparten un mismo espacio de nombres: varios dominios que utilizan un espacio de nombres continuo forman un árbol.

  • Un dominio puede tener subdominios y así se construye el árbol (ejemplos del documento: us.Nextinfo.priv, es.Nextinfo.priv).
  • El dominio raíz es el que está en la cima del árbol.
Nextinfo.priv                    ← dominio raíz (cima del árbol)
 └── es.Nextinfo.priv             ← subdominio de Nextinfo.priv
      └── mail.es.Nextinfo.priv   ← subdominio de es.Nextinfo.priv
Cada subdominio añade su etiqueta delante del nombre de su padre (es. + Nextinfo.priv): por eso el espacio de nombres es continuo.
Si el espacio de nombres no es continuo, ya no hablamos de un árbol, sino de un bosque.

3. Bosque

Agrupación de dominios con un único esquema

  • Un bosque es una agrupación de varios dominios Active Directory y posee un único esquema.
  • El primer dominio instalado en un bosque se llama dominio raíz del bosque.
  • Varios árboles de dominio cuyo espacio de nombres no es continuo representan un bosque.
                         BOSQUE
           ┌───────────────┴───────────────┐
     Nextinfo.priv                   Infonext.local
           │                               │
   es.Nextinfo.priv                es.Infonext.local
       (árbol 1)                       (árbol 2)
Los dos árboles del ejemplo no comparten espacio de nombres (Nextinfo.priv frente a Infonext.local), pero pertenecen al mismo bosque y, por tanto, comparten un único esquema.
