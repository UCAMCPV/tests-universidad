Resumen: Niveles funcionales

Qué son los niveles funcionales de bosque y de dominio en Windows Server 2016, qué activa cada uno y cómo se elevan (y por qué no hay vuelta atrás).

1. Qué son los niveles funcionales

Los niveles funcionales hacen dos cosas a la vez:

  • Determinan las funcionalidades activas dentro de un dominio o de un bosque.
  • Definen qué sistemas operativos pueden albergar el rol de controlador de dominio en ese dominio o bosque.
NivelAlcance de las funcionalidades que activa
De bosqueEl conjunto del bosque
De dominioSolo ese dominio concreto

Con Windows Server 2016 hay cinco niveles disponibles, tanto de bosque como de dominio:

Windows Server 2008 → 2008 R2 → 2012 → 2012 R2 → 2016
Los niveles de Windows Server 2003 han desaparecido por el fin del ciclo de vida de ese sistema.

2. Niveles funcionales de bosque

Qué activa cada nivel de bosque

Nivel de bosqueFuncionalidades para todo el bosque
Windows Server 2008
  • Implementar controladores de dominio de solo lectura (RODC).
  • Modificar un objeto InetOrgPerson en el objeto Usuario.
  • Modificar el nombre de un dominio.
  • Crear relaciones de confianza entre bosques para compartir recursos.
Windows Server 2008 R2Activar la papelera de reciclaje de Active Directory para recuperar objetos eliminados por accidente.
Windows Server 2012 y 2012 R2Ninguna funcionalidad suplementaria.
Windows Server 2016Definir una caducidad para la pertenencia a un grupo: agregar un usuario a un grupo durante un tiempo limitado.
Bosque: 2008 RODC, InetOrgPerson→Usuario, renombrar dominios y confianzas entre bosques · 2008 R2 papelera de reciclaje · 2012/2012 R2 nada · 2016 pertenencia a grupos con caducidad.

3. Niveles funcionales de dominio

Nivel de dominio Windows Server 2008 (el que más aporta)

  • Almacenar las zonas DNS en las particiones del directorio, para replicarlas en todos los controladores de dominio.
  • Renombrar los controladores de dominio con la herramienta Netdom.exe.
  • Redirigir los contenedores (el documento dice «unidades organizativas») Usuarios y Equipos.
  • Los atributos de grupo se replican como valores múltiples en un único objeto: dos administradores pueden modificar a la vez un grupo sin que se pierdan las modificaciones.
  • El atributo LastLogonTimestamp está activo en todas las cuentas de usuario: guarda la fecha y hora de la última conexión al dominio y se replica en todos los DC del dominio.
  • Delegación de autenticación para las cuentas de usuario: una aplicación que se ejecuta con una cuenta de servicio puede autenticar a los usuarios en el dominio. La usan a menudo las aplicaciones con Kerberos (SSO, Single Sign On).
  • Cifrado Kerberos con AES de 128 y 256 bits (Advanced Encryption Standard).
  • Controladores de dominio de solo lectura para mejorar la seguridad y la autenticación de sitios remotos.
  • Replicación de la carpeta SYSVOL entre DC con DFS-R (Distributed File System Replication), frente al tradicional FRS (File Replication System).
  • Directivas de contraseña para un grupo de usuarios, en lugar de la directiva predeterminada del dominio (Default Domain Policy).

El resto de niveles de dominio

Nivel de dominioQué añade
Windows Server 2008 R2Funcionalidades avanzadas de inicio de sesión y autenticación Kerberos. En entornos federados con AD FS (Active Directory Federation Services) permite leer el contenido de los tokens de autenticación en cada acceso a una aplicación.
Windows Server 2012 y 2012 R2Ninguna funcionalidad suplementaria.
Windows Server 2016Ninguna funcionalidad suplementaria.
Windows Server 2003 no se aborda: solo garantiza compatibilidad con versiones que ya no tienen soporte de Microsoft, como transición hasta elevar a 2008 R2 o superior. No hay motivo para usarlo en producción con servidores Windows Server 2016.
Trampas típicas: la papelera de reciclaje es del nivel de bosque 2008 R2, no del de dominio; la caducidad de la pertenencia a grupos es del nivel de bosque 2016; renombrar un dominio es de bosque 2008, pero renombrar controladores con Netdom.exe es de dominio 2008.

4. Elevar el nivel funcional

Nivel funcional de dominio

  1. Abrir Dominios y confianzas de Active Directory (también funciona con Usuarios y equipos de Active Directory).
  2. Desplegar el árbol, seleccionar el dominio, clic derecho → Elevar el nivel funcional de dominio.
  3. Elegir el nivel en la lista desplegable → Elevar.

Nivel funcional de bosque

  1. Abrir Dominios y confianzas de Active Directory.
  2. Seleccionar la raíz de la consola, clic derecho en Dominios y confianzas de Active Directory → Elevar nivel funcional del bosque.
  3. Elegir el nivel en la lista desplegable → Elevar.
Precaución: al elevar el nivel funcional del bosque no es posible restaurarlo a un nivel inferior.

Ideas clave para el examen

  • Nivel funcional = funcionalidades activas + qué SO pueden ser DC.
  • WS 2016 admite cinco niveles (2008 a 2016); los de 2003 desaparecen por fin de ciclo de vida.
  • Bosque: 2008 RODC, InetOrgPerson, renombrar dominios, confianzas entre bosques · 2008 R2 papelera · 2016 pertenencia temporal a grupos.
  • Dominio 2008: DNS en particiones del directorio, Netdom.exe, LastLogonTimestamp, AES 128/256, RODC, SYSVOL con DFS-R, directivas de contraseña por grupo… · 2008 R2 Kerberos avanzado con AD FS · 2012, 2012 R2 y 2016 nada nuevo.
  • Se elevan desde Dominios y confianzas de AD; el de dominio, también desde Usuarios y equipos. Elevar el bosque es irreversible.
